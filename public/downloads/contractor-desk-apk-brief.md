# AlterCraft Contractor Desk

Date: 2026-07-02

## What This App Is

Contractor Desk is a test Android app for AlterCraft's B2B execution model.

It is made for designers, architects, builders, developers, contractors and realtors who already have work in hand but need an execution partner. The idea is simple:

Bring the project. AlterCraft handles the work.

The partner can create a project request, choose the type of work, get an approximate price range, save the request, and then track what needs to happen next.

## Who It Helps

- A designer who has a client but no execution team.
- A builder who needs labour or site support.
- A developer who wants one team for concrete, exterior, interior and finishing work.
- An architect who wants execution handled without building an in-house team.
- A realtor or contractor who wants to pass work to AlterCraft with clear scope and pricing.

## What The App Can Do Now

### Create a Project Request

The partner can enter:

- Role and contact details
- Company and city
- Work category
- Labour-only, material-only, labour with material, turnkey or white-label model
- Approximate work area
- Property type, start date, material grade and notes

### Show an Approximate Estimate

The app shows:

- Approximate rate
- Estimated project range
- Token amount
- Expected work timeline
- What is included in the selected work model

This is not a final quote. It is a first estimate for discussion.

### Save Projects

Saved projects appear in the Work Desk. This helps AlterCraft or the partner see:

- Active projects
- Missing contact details
- Missing scope files or site photos
- Pending token/payment status
- Missing proof before the work moves ahead

### Add Site Proof

The app can save proof notes such as:

- Before photo
- Progress photo
- Material count
- Defect close-up
- Supervisor note

File upload is not live yet. For now, the app saves file names and proof notes for testing the workflow.

### Track Money

The Money section separates:

- Cash available
- Pending receivables
- Material budget
- Labour budget
- Supervision budget
- Reserve amount

It also shows the next token that should be collected before work moves forward.

### Create Message Drafts

The Drafts section can create ready-to-send text for:

- Work order
- Vendor message
- Client update
- Short content or reel idea

These are built-in templates. They are not sent automatically.

If copy does not work on the device, the app shows the text in a manual copy box.

### Backup And Restore

The app can copy all saved project data as text. This can be used for manual backup or handoff.

## Important Limits

This is still a test APK.

It does not yet include:

- Online login
- Team accounts
- Real cloud file upload
- Real payment collection
- Same data across multiple phones
- Play Store-ready release build

The app is useful for testing the workflow and showing the business model. It is not yet the final production app.

## How To Test

1. Install `contractor-desk-debug.apk` on an Android phone.
2. Open `AlterCraft Contractor Desk`.
3. Create a sample project request.
4. Save the request.
5. Open Work Desk.
6. Check Projects, Proof, Money and Drafts.
7. Create a message draft and test copy/manual copy.

Android may show a warning because this is a test APK, not a Play Store release.
