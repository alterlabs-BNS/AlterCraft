## 1. Spec sheet

| Field | S01 Shoe Bench |
|---|---|
| Category | Entryway storage |
| Target keywords | shoe bench, shoe rack seating, shoe rack with seat |
| Ideal use case | Apartment entrance / foyer where people sit to wear shoes and need a drop zone |
| Design style | Warm modern / compact urban |
| Seat height | 450 mm (fixed — comfortable sitting height incl. cushion) |
| Depth | 350 mm standard · 300 mm slim · 400 mm deep *(confirm)* |
| Standard widths | 2-seater **900 mm** · 3-seater **1200 mm** · Family **1500 mm** |
| Custom range | W 600–1800 mm · D 300–420 mm · H 420–480 mm |
| Storage capacity | ≈ 2 pairs per 300 mm width per shelf → 900 mm = 9–12 pairs, 1200 mm = 12–16, 1500 mm = 15–20 *(confirm on prototype)* |
| Carcass material | 18 mm BWP ply (default) · 18 mm HDHMR (value option) |
| Shutters / fronts | 18 mm HDHMR or ply with laminate / veneer |
| Seat top | Solid wood-look laminate top · or 50 mm foam cushion, fabric/leatherette |
| Finishes | Walnut · Natural oak · Ash · Warm beige · Matte white · Charcoal accent |
| Hardware | Soft-close hinges, profile handle or push-to-open, levelling feet / 100 mm plinth |
| Ventilation | Back slots or louvered shutter on closed versions (shoe odour) |
| Fabrication complexity | Low — flat carcass, 1–2 shelves, optional doors/drawer |
| Price band | ₹14k–22k (900) · ₹18k–28k (1200) · ₹22k–34k (1500) *(confirm with BOM)* |
| Lead time | 10–14 working days after design approval *(confirm)* |
